Resolve all paths from the Pennywise repository root (the ancestor containing `learning/`),
not from the caller's working directory. Read `learning/TEACHING.md` before proceeding.

Use the requested topic, or pick a completed module from `learning/progress.json`.
Read its relevant source lessons via `learning/curriculum.md`. Ask one interview question at
a time and wait for Nathan's answer. Start from an inspected Pennywise code path or decision;
use an explicitly hypothetical Pennywise scenario when necessary. Include AWS trade-offs when
relevant to the integration, distinguishing actual choices from proposals.
Challenge reasoning about failure, concurrency and scale; fill gaps only after he tries.
Keep it brisk and record useful weaknesses in learning notes without altering completion.
