# modules/ — one folder per lesson-module

Each `NN-slug/` holds:

- `BRIEF.md` — the scenario handed to Nathan (problem-first, concept **not** named)
- `NOTES.md` — concepts, trade-offs, interview angle (written *after* he's reasoned through it)
- `TASKS.md` — exercises / TODOs
- `src/`, tests, compose files — any code specific to that module

See `../curriculum.md` for the map of all 30 modules and their source lessons.
Created on demand as each module is taught.
